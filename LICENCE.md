## 🧩 About

**Smite Companion** is a curated list of Smite open-source tools:

- **Overlays** — on-screen helpers, layout notes, cooldown tracker, minimap notes
- **Quality-of-Life Helpers** — item catalog, build manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- Cooldown Tracker — monitor ability timers
- Minimap Notes — annotate map objectives
- Replay Notes — record and review match runs
- Playback Speed — adjust replay playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Item Catalog — browse items, skins, voice packs
- Custom Build Notes — organize player builds
- Skin Manager — preview and manage cosmetics

### 🏋️ Match Layout
- Practice Mode Notes — segment study on any map
- Objective Timer — track buffs and jungle timers
- Build Planner — plan item purchases in the editor
